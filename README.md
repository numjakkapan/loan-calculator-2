# 💰 แอปพลิเคชันคำนวณสินเชื่อ

แอปพลิเคชันสำหรับคำนวณสินเชื่อแบบลดต้นลดดอก (Declining Balance Loan)

## ✨ คุณสมบัติ

- ✅ คำนวณดอกเบี้ยแบบเป็นวัน (365 วัน/ปี)
- ✅ ค่างวดเท่ากันทุกงวด
- ✅ แสดงตารางรายละเอียดการชำระ
- ✅ คัดลอกข้อความให้ลูกค้าได้ทันที
- ✅ ทำงานแม้ไม่มีอินเทอร์เน็ต
- ✅ ติดตั้งได้บนโทรศัพท์ Android/iOS

## 📱 วิธีการติดตั้ง

### Android
1. เปิดแอป Chrome หรือ Edge
2. ไปที่เว็บไซต์ของแอปพลิเคชัน
3. คลิกแบนเนอร์ "📲 ติดตั้งแอปพลิเคชันลงโทรศัพท์ของคุณ"
4. กดปุ่ม "ติดตั้ง"
5. แอปพลิเคชันจะปรากฏบนหน้าจอหลัก

### iOS
1. เปิด Safari
2. ไปที่เว็บไซต์ของแอปพลิเคชัน
3. กดปุ่ม "แชร์" 
4. เลือก "เพิ่มไปยังหน้าจอโฮม"
5. ตั้งชื่อและกด "เพิ่ม"

## 🚀 วิธีการใช้งาน

### ขั้นตอนพื้นฐาน
1. **กรอกจำนวนเงินกู้** - ใส่จำนวนเงินที่ลูกค้ากู้
2. **กรอกอัตราดอกเบี้ยต่อปี** - ใส่อัตรา % ต่อปี
3. **กรอกระยะเวลากู้** - ใส่ปี หรือเดือน
4. **เลือกวันเริ่มกู้** - วันที่จำนวนเงินถูกปล่อยให้
5. **เลือกวันชำระงวดแรก** - วันที่จะชำระงวดแรก
6. **กดปุ่มคำนวนใหม่** - ระบบจะคำนวณทันที

### ผลลัพธ์
- ยอดรวมดอกเบี้ย
- รวมชำระทั้งสิ้น
- วงเงินรายเดือน
- จำนวนงวด

### ดูรายละเอียด
- กดปุ่ม "📊 ดูตารางรายละเอียด" เพื่อดูการชำระแต่ละงวด
- ตารางแสดง: งวด, วันชำระ, จำนวนวัน, ยอดคงเหลือต้น, ดอกเบี้ย, เงินต้น, ชำระรวม

### ส่งข้อความให้ลูกค้า
1. ระบบจะสร้างข้อความอัตโนมัติในส่วน "ข้อความส่งให้ลูกค้า"
2. กดปุ่ม "📋 คัดลอกข้อความ"
3. ข้อความจะถูกคัดลอก และแสดง "✓ คัดลอกเรียบร้อย"
4. ส่งให้ลูกค้าผ่าน SMS, Email, หรือแชท

## 📊 ตัวอย่างการใช้งาน

### ข้อมูลตัวอย่าง
- จำนวนเงินกู้: 100,000 บาท
- อัตราดอกเบี้ยต่อปี: 5%
- ระยะเวลา: 3 ปี (36 เดือน)

### ผลลัพธ์
- อัตราดอกเบี้ยต่อเดือน: 0.42%
- ชำระเดือนละ: ฿2,994
- ยอดรวมดอกเบี้ย: ฿7,785
- รวมชำระทั้งสิ้น: ฿107,785

## 💡 การคำนวณ

### สูตร
- อัตราดอกเบี้ยต่อเดือน = อัตรา % ต่อปี ÷ 12
- ดอกเบี้ย = ยอดคงเหลือ × อัตราต่อวัน × จำนวนวัน
- เงินต้น = ค่างวด - ดอกเบี้ย
- ยอดคงเหลือ = ยอดคงเหลือเดิม - เงินต้น

### วิธีการคำนวณดอกเบี้ย
- ดอกเบี้ยคำนวณแบบเป็นวัน (365 วัน/ปี)
- ยอดเหลือลดลงทุกเดือน
- ดอกเบี้ยลดลงทีละน้อย
- ค่างวดเท่ากันทุกเดือน

## 🔒 ความปลอดภัย

- ✅ ข้อมูลทั้งหมดเก็บไว้ในโทรศัพท์ของคุณเท่านั้น
- ✅ ไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ใด
- ✅ สามารถใช้งานแม้ไม่มีอินเทอร์เน็ต

## 🛠️ การติดตั้งบนเซิร์ฟเวอร์ของคุณ

### ต้องการไฟล์
1. `index.html` - ไฟล์หลักของแอป
2. `manifest.json` - ไฟล์กำหนดคุณสมบัติ PWA
3. `sw.js` - Service Worker

### ขั้นตอนการติดตั้ง
1. อัปโหลดไฟล์ทั้ง 3 ไฟล์ไปยังเซิร์ฟเวอร์ของคุณ
2. ให้แน่ใจว่าเซิร์ฟเวอร์ใช้ HTTPS
3. ไปที่เว็บไซต์และลองติดตั้งแอป

### ข้อกำหนด
- ✅ HTTPS (บังคับ)
- ✅ Web Server (Apache, Nginx, Node.js, เป็นต้น)
- ✅ Modern Browser ที่รองรับ PWA
